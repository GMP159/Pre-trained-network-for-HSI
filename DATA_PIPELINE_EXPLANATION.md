# Data Pipeline Explanation - src2

## TIFF File Structure

Each TIFF file in `D:\Thesis_new\new_data` has the following structure:

```
Shape: (64, 64, 257)
Bands 1-256:  Spectral data (hyperspectral measurements)
Band 257:     Mask channel (binary or auxiliary data)
```

## Data Loading Pipeline

### Step 1: TIFF File Reading

```python
# In src2/data/dataset.py
with rasterio.open(tiff_path) as src:
    patch_data = src.read([band_index])  # Shape: (1, H, W)
    # patch_data is shape (257, patch_h, patch_w) for full band range
```

### Step 2: Band Separation

```python
# Separate spectral data from mask
spectral_data = patch_data[:256]     # Shape: (256, 64, 64) - spectral bands
mask_data = patch_data[256]          # Shape: (64, 64) - mask band
```

### Step 3: Normalization (SPECTRAL ONLY)

```python
# Normalize spectral data using per-patch z-score normalization
patch_mean = spectral_data.mean(axis=(1, 2), keepdims=True)  # Mean per band
patch_std = spectral_data.std(axis=(1, 2), keepdims=True)    # Std per band
patch_std = np.where(patch_std == 0, 1.0, patch_std)        # Avoid division by zero

# Apply normalization
spectral_normalized = (spectral_data - patch_mean) / patch_std

# Result: Normalized spectral data with mean ≈ 0, std ≈ 1 per band
# Shape: (256, 64, 64)
```

### Step 4: Mask is NOT Normalized

```python
# Mask is kept as-is without normalization
mask = mask_data.astype(np.float32)
# Shape: (64, 64) - values preserved exactly as in TIFF
```

### Step 5: Return Data Tuple

```python
# Dataset returns 3-tuple
return (spectral_patch, mask_patch, file_label)
# 
# spectral_patch: shape (64, 64, 256) - normalized spectral data
# mask_patch:     shape (64, 64)      - raw mask values
# file_label:     int                  - file ID/label
```

## Model Input/Output

### Model Input
```
Input to model: spectral_patch only
Shape: (batch_size, 64, 64, 256)
Data: Normalized spectral data (mean ≈ 0, std ≈ 1)
```

### Model Processing
```
1. Patch Embedding: 64×64×256 → (256 spatial patches, 16 spectral groups, 128-dim embeddings)
   - Spatial: 4×4 patches from 64×64 → 16×16 = 256 patches
   - Spectral: 256 bands / 16 = 16 spectral groups
   - Output shape: (batch, 256, 16, 128)

2. Positional Encoding: Add learnable position embeddings

3. Transformer Blocks: Process with factorized spatial-spectral attention

4. Reconstruction Head: 
   - Input: (batch, 256, 16, 128)
   - Output: (batch, 64, 64, 256) - reconstructed spectral data
```

### Model Uses Mask Internally
```
During pre-training:
- Mask strategy: Tube masking (85% spatial regions masked)
- Loss computed: Only on masked regions
- Mask from model: Generated independently, NOT from file mask_data
```

## Verification: Is Data Normalized?

**YES**, the data is normalized before being passed to the model:

1. **Where**: In `src2/data/dataset.py`, in the `TIFFHSIDataset.__getitem__` method
2. **When**: During data loading, before yielding to model
3. **What**: Only spectral data (bands 1-256) is normalized
4. **How**: Per-band z-score normalization: `(x - mean) / std`
5. **Mask**: NOT normalized, kept raw

### Normalization Code Reference
```python
# In src2/data/dataset.py, TIFFHSIDataset.__getitem__
spectral_data = patch_data[:256]  # Get spectral bands
patch_mean = spectral_data.mean(axis=(1, 2), keepdims=True)
patch_std = spectral_data.std(axis=(1, 2), keepdims=True)
patch_std = np.where(patch_std == 0, 1.0, patch_std)
patch = (spectral_data - patch_mean) / patch_std  # Normalized
```

## Training Pipeline

```
1. Load TIFF file with rasterio
   ↓
2. Extract 64×64 patches (or use full image)
   ↓
3. Separate bands 1-256 (spectral) and 257 (mask)
   ↓
4. Normalize spectral data (mask untouched)
   ↓
5. Model receives normalized spectral data
   ↓
6. Model generates internal mask (85% spatial)
   ↓
7. Compute reconstruction loss on masked regions
   ↓
8. Backpropagate and update weights
```

## Important Notes

- **Mask from file**: Band 257, NOT normalized, can be used for post-processing
- **Mask during training**: Generated by model's masking strategy, independent of file mask
- **Spectral normalization**: Critical for stable training with transformer
- **Architecture**: 256 bands → 16 spectral groups (clean 256÷16 division)
- **Patch size**: 4×4 spatial, 16 spectral → 256-dimensional patch embeddings
